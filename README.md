# JavaScript Course

A beginner-friendly JavaScript course with practical examples, exercises, and small projects.

The repository contains the code used throughout the course, starting with JavaScript fundamentals and gradually moving to browser APIs, DOM manipulation, events, and a Todo List project.

## 📚 Course Topics

The course currently covers:

### JavaScript Fundamentals

- Variables
- Data types and `typeof`
- Type conversions
- Operators and comparisons
- Conditional statements
- Logical operators
- Nullish coalescing
- Functions
- Loops
- Objects
- Object copying
- Object methods and `this`
- Arrays
- Primitive methods
- Number and string methods
- Callback functions
- Array methods
- `Object.keys()`, `Object.values()`, `Object.entries()`
- Destructuring assignment

### Browser JavaScript

- HTML and CSS review
- Browser environment and the global `window` object
- DOM navigation and element searching
- Browser events
- `addEventListener()` and `removeEventListener()`
- HTML attributes and DOM properties
- `dataset`
- Styles and CSS classes

### Practical Projects

The course also includes practical work where previously learned concepts are combined into small projects:

- 🧮 Simple Calculator
- 📝 Todo List
- 🌐 Working with the DOM and browser events
- 🔧 Code refactoring
- 🌿 Introduction to Git and GitHub

## 🎯 Learning Approach

The course focuses on understanding JavaScript through simple explanations and practical examples.

The main idea is:

> Learn a concept → see a simple example → practice it → use it in a project.

The examples are intentionally kept straightforward so that beginners can concentrate on understanding JavaScript rather than dealing with unnecessary complexity.

## 🛠️ Technologies

- JavaScript
- HTML
- CSS
- Browser APIs
- Git
- GitHub

No frameworks are required for the lessons. The course primarily uses vanilla JavaScript.

## 🚀 How to Use This Repository

Clone the repository:

```bash
git clone https://github.com/niskadevla/js-course.git
```

Open the project in your code editor, for example WebStorm or VS Code.

Each lesson has its own folder. Open the folder for the lesson you are studying and experiment with the code.

For browser-based lessons, open the corresponding HTML file in a browser or use a local development server.
